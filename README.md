# 双电机小车基础版

保留编码器测速、双轮速度 PID、8 路灰度循迹、MPU6050 航向纠偏、OLED、串口和按键。接线沿用原工程。

## 先看这三个文件

- `empty.c`：每 10ms 读取传感器、处理按键、调用路线控制，再把目标轮速交给 PID。
- `car.c`：开头是路线表，`car_tick()` 中只有转向、直线、圆弧三种动作。
- `pid.c`：根据“目标计数 - 实测计数”计算 PWM，保留积分和输出限幅。

直线用双轮平均里程判断终点，用陀螺仪修正车头方向。圆弧先给出基础轮速差，再用灰度 PD 跟随黑线；陀螺仪判断是否转过半圈。转向时两轮都前进。

速度 PID 直接放在主程序中，省去独立的 `drive` 层、速度斜坡和横向位置估算。底层的编码器、灰度、陀螺仪、OLED 驱动各自保留在对应文件中。

## 怎么用

1. 上电后静止约 3 秒，等待陀螺仪校准完成。
2. 待机时按 **KEY2** 选择 M1～M4，按 **KEY1** 启动。
3. 行驶中按 **KEY2** 停车。停车清除 PID，制动约 300ms 后关闭驱动。

| 项目 | 路线 |
| --- | --- |
| M1 | A → B |
| M2 | A → B → C → D → A |
| M3 | A → C → B → D → A |
| M4 | M3 连续四圈 |

场地按 AB=1000mm、AD=800mm、半圆半径=400mm 设置，黑线只有 B-C、D-A 两段半圆。M1/M2 出发朝 B，M3/M4 出发朝 C。每到顶点，蜂鸣器和 LED 提示约 120ms。

## 先填四个参数

打开 `app_config.h`，填写实际轮径、每圈计数和轮距：

```c
#define CAR_WHEEL_DIAMETER_MM           0.0f
#define CAR_LEFT_COUNTS_PER_WHEEL_REV   0.0f
#define CAR_RIGHT_COUNTS_PER_WHEEL_REV  0.0f
#define CAR_WHEEL_TRACK_MM              0.0f
```

默认 0 表示未标定，显示 CFG 并拒绝启动，但可以手转车轮查看编码器。

- **每圈计数**：手转车轮 10 圈，用串口 `total` 的增加量除以 10。当前只数 A 相上升沿，属于 1 倍频；按减速箱输出轴/车轮转一圈标定。
- **方向**：向前推车时左右计数都应增加，否则修改对应 `ENCODER_*_SIGN`；电机前进方向由 `MOTOR_*_FORWARD_SIGN` 调整。
- **陀螺仪**：手动左转时 Y 应增加，否则修改 `IMU_YAW_SIGN`。Y 是相对积分角度，每次启动路线清零，长期运行会漂移。
- **灰度**：从车头朝前看，S0 在最左边；默认黑=低电平。白底应显示 G00，中间黑线常为 G18。全白、全黑或分散黑区不用于纠偏。
- **调参**：先架空检查方向，再降低轮速和 PWM 上限调速度 PID，然后调航向与灰度 PD。`CAR_STOP_LEAD_MM` 是实测停车提前量。

速度反馈单位为“计数/10ms”，不是 rpm：

```text
每计数距离(mm) = π × 轮径 / 每圈计数
目标计数/10ms = 目标轮速(mm/s) × 0.01 / 每计数距离
```

## 接线

| 信号 | MSPM0G3507 引脚 |
| --- | --- |
| 左电机 AIN1 / AIN2 / PWMA | PA8 / PA9 / PA12 |
| 右电机 BIN1 / BIN2 / PWMB | PA10 / PA11 / PA13 |
| TB6612 STBY | PB24 |
| 左编码器 A / B | PA17 / PA18 |
| 右编码器 A / B | PA22 / PA23 |
| 灰度 S0～S7 | PB0 / PB1 / PB4 / PB5 / PB8 / PB9 / PB10 / PB11 |
| MPU6050 SDA / SCL | PA0 / PA1，I2C0，地址 0x68 |
| OLED SDA / SCL | PB3 / PB2，I2C1 |
| KEY1 / KEY2 | PB6 / PB7，高电平按下 |
| 蜂鸣器驱动模块 IN | PA24 |
| 提示 LED / 运行 LED | PA14 / PA15 |
| 串口 TX / RX | PA28 / PA31，115200，8N1 |

各模块共地，MCU 侧信号用 3.3V；5V 输出先转换电平。MPU6050 的 AD0 接低，两组 I2C 上拉到 3.3V。TB6612 的 VM 接匹配电机的电源，VCC 接 3.3V，驱动能力须按电机堵转电流核对。

OLED 的 E 是累计计数，G 是灰度掩码，Y 是角度。串口 `cnt` 是最近 10ms 的计数，`total` 用于手转标定。

## 编译和检查

在 CCS 中 Clean/Rebuild，或执行：

```powershell
./tools/build.ps1
./tools/test.ps1
```

固件输出为 `.build/basic_car.out` 和 `.build/basic_car.bin`。构建脚本默认使用 SDK 2.11.00.07、SysConfig 1.26.2、TI Arm Clang 4.0.4.LTS，可通过脚本参数修改安装目录。

保留的停车保护：CFG 参数未填、IMU 通信异常、LINE 持续失线、DIR 编码器反向、STALL 无脉冲、TIME 超时、DIST 里程异常。IMU 异常需检查后复位；弧线接入最多寻线 800ms，接线后失线 150ms 停车，终点附近允许前置探头提前离线。

测试覆盖四种路线、四圈停止、灰度解算、PID 限幅和异常停车；仿真通过不代表实车达标。当前尺寸参数仍未标定，上车前须填写参数并验证转弯衔接、漂移和停车距离。
